# 🎮 Android Disney Game Suite

An interactive game suite for Android inspired by popular Disney characters, developed as part of a team project. The app includes multiple gameplay modes, user authentication, and player progression tracking — all wrapped in a polished mobile experience.

> 🛠 Built using Java, Android SDK, XML layouts, and local data storage

---

## 📱 Features

- 🧩 **Game Modes**  
  Supports single player, two-player, and online multiplayer sessions.

- 🔐 **User Authentication**  
  Secure login and player registration with unique session handling.

- 🧠 **Player Registry**  
  Tracks player stats, history, and game progression.

- 🎨 **Custom UI/UX**  
  Disney-themed assets and animations for an immersive experience.

---

## 🏗️ Architecture Overview

- **Front-end**: Android XML Layouts, Activities & Fragments  
- **Back-end**: Java-based logic for gameplay state and user sessions  
- **Persistence**: Local file/database storage for player registry
